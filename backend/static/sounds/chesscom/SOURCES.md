# Chess.com sound samples

These MP3 files are unmodified downloads from the Chess.com CDN. Source collection: https://www.chess.com/forum/view/general/chessboard-sound-files?page=2#comment-89885805 (Madoby, post #22); the additional game outcome samples are linked in post #31 on the same page.

The source URL, SHA-256 and byte count of each file are recorded in manifest.json. Attribution: Chess.com. These third-party audio assets are separate from the application’s GPL license; the forum does not specify an open-source license for the samples.

Playback mapping: move-self / move-opponent, capture, castle, promote, move-check, premove, game-start; checkmate combines move-check and game-end. Other outcomes use game-win-long, game-lose or game-draw. notify is used for incoming game challenges, illegal for invalid move attempts, tenseconds for the player's low-time warning.
